# ⚡ Cyber Motion Portfolio (Anime.js Aesthetic)

An award-winning developer portfolio web application built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS v4**, **Framer Motion**, and **Lenis Smooth Scroll** inspired by the sleek vector & particle aesthetic of [Anime.js](https://animejs.com/).

Designed specifically for developers who love **high-fidelity kinetic visuals, neon glow effects, and micro-interactions** without heavy or dizzying 3D camera transitions.

---

## ✨ Features & Highlights

- **🎯 Anime.js Style Vector Physics:** Real-time 2D interactive canvas particle grid reacting dynamically to cursor velocity and coordinates.
- **🎛️ Live Visual Control Deck:** Instant live controls to tweak velocity, particle density, and theme spectrums (Cyan, Purple, Magenta, Emerald).
- **💫 Kinetic Typography & Staggered Motion:** High-impact entrance animations and spring physics.
- **🧈 Lenis Momentum Smooth Scroll:** Silky smooth scrolling experience.
- **💎 Glassmorphism Bento Grid:** Modern showcase cards with glowing hover states, live stats, tech tags, and external preview links.
- **⚡ Technical Stack Matrix:** Visual capability cards with glowing animated skill level bars.
- **🚀 Interactive Terminal CLI:** Built-in interactive bash emulator (`help`, `skills`, `projects`, `contact`, `hire`) + Direct Transmission Contact Form with celebration confetti (`canvas-confetti`).
- **🕒 Real-time Bangkok Timezone Clock:** Dynamic local time indicator and live availability badge.
- **📱 Fully Responsive:** Clean mobile-first design with smooth custom cursor trailer on desktop.

## 🛠️ Tech Stack

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/) + React 19
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) + Custom Cyber Neon Glow Design Tokens
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [Anime.js](https://animejs.com/)
- **Smooth Scroll:** [Lenis](https://lenis.darkroom.engineering/)
- **Icons:** [Lucide Icons](https://lucide.dev/) & Custom SVG Vector Icons
- **Effects:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Getting Started

### 1. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production

```bash
npm run build
npm start
```

---

## ✏️ How to Customize Your Data

All portfolio data (Personal bio, Projects, Skills, Experiences, Links) is neatly organized in a single file:

📂 **`src/data/portfolioData.ts`**

Simply edit this file to update your personal details, project showcase cards, and career journey!

---

## 🚢 Deployment

Easily deploy to **Vercel** with zero-configuration:

1. Push your repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. Import your GitHub repository to [Vercel](https://vercel.com).
3. Click **Deploy**.
